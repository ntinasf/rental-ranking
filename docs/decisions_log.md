| 2026-07-30 | Join integrity is verified with an **absolute** per-city resolution check plus a cross-city disjointness check (summed set sizes vs size of union), not by comparing per-city intersections against the post-concat intersection | The relational form: sum of per-city intersection sizes == intersection size after concat | The relational check is invariant-preserving, not correctness-establishing: if the salt were wrong for an entity in *every* city, per-city intersections are all empty, the sum is 0, the total is 0, and 0 == 0 passes while nothing joins.
